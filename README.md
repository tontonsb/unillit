# Unillit

Feel illiterate in a foreign script? Un-illiterate yourself!

## Development

Vue 3 TypeScript project with a Supabase backend for optional stats.

Prerequisites: node & git.

Clone the repo and install the dependencies:

```sh
git clone https://github.com/tontonsb/unillit.git
npm install
```

Launch dev server:

```sh
npm run dev
```

Type-Check, Compile and test if it builds:

```sh
npm run build
```

Or type-check only:

```sh
npm run type-check
```

Run tets:

```sh
npm run test:unit -- --run
```

Check your code style and stuff:

```sh
npm run lint
```

or each tool separately:

```sh
npm run lint:oxlint # discovers likely errors
npm run lint:eslint # checks TS & HTML style
npm run lint:stylelint # CSS code style
```
